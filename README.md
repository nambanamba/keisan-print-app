# 🧮 理科「今日の計算問題」印刷・練習アプリ

四谷大塚「予習シリーズ」5年下・理科の計算問題に特化した、範囲指定＋印刷＋その場で解くアプリです。姉妹アプリ [kosukequiz-battle](https://github.com/nambanamba/kosukequiz-battle)（対戦型一問一答クイズ）から、計算問題機能だけを独立させたものです。

---

## 🌟 特長

- 回の範囲（例：1〜2）と問題数を指定して出題
- 「問題を印刷する」「解答・解説を印刷する」をそれぞれA4で印刷可能（紙で解く用）
- 画面上でもそのまま解いて、こたえ・解説を確認できる
- 出題はテキストの掲載順（回→ページ→問番号）。ランダムに並べ替えません
- 正解した問題を登録して、まだ正解していない問題だけを出題できます
- 記録はブラウザのlocalStorageに保存されるだけの簡単なもので、対戦クイズ本体の暗記管理とは混ざりません

## 🚀 使い方

1. `index.html` をブラウザで開きます。
2. 回の範囲・問題数を指定します（空欄・未指定なら全範囲）。
3. 「計算問題を始める」で画面上で解く、または「印刷する」ボタンでA4プリントを作成します。
4. 画面で解いたときは「⭕ できた／❌ できなかった」で記録されます。紙で解いた分は
   「✅ 正解した問題を登録する」からまとめてチェックできます。
5. 「正解した問題を除く」にチェックを入れると、まだ正解していない問題だけが出題されます。

## 📁 ファイル構成

- `index.html` - アプリ本体
- `data.js` - 理科の計算問題データ（`QA_DATA`、kosukequiz-battleの`data.js`内`kind:"calc"`の項目を移植）
- `images/` - 問題で参照する図版画像（切り出しは元データ側（`quiz_csv_理科`）の担当）

## 💾 正解の記録について

- ブラウザのlocalStorage（キー：`keisan_print_stats_v1`）に、問題idごとの
  `{correct, wrong, lastAnswered, lastCorrectAt}` を保存します
- 記録はブラウザごと・端末ごとです。別の端末とは共有されません
- 「🗑️ 正解の記録をすべて消す」でリセットできます

## 🔄 データの更新方法

新しい回の理科データが`quiz_csv_理科`から届いたら、kosukequiz-battle担当セッションが計算問題（`kind:"calc"`）の項目だけをこの`data.js`に追記します（暗記系の項目はkosukequiz-battle本体側に追記）。
