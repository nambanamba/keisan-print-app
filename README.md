# 🧮 理科「今日の計算問題」印刷・練習アプリ

四谷大塚「予習シリーズ」5年下・理科の計算問題に特化した、範囲指定＋印刷＋その場で解くアプリです。姉妹アプリ [kosukequiz-battle](https://github.com/nambanamba/kosukequiz-battle)（対戦型一問一答クイズ）から、計算問題機能だけを独立させたものです。

---

## 🌟 特長

- 回の範囲（例：1〜2）と問題数を指定して出題
- 「問題を印刷する」「解答・解説を印刷する」をそれぞれA4で印刷可能（紙で解く用）
- 画面上でもそのまま解いて、こたえ・解説を確認できる
- 進捗・正誤の記録は行わない無状態のツール（対戦クイズ本体の暗記管理とは混ぜない）

## 🚀 使い方

1. `index.html` をブラウザで開きます。
2. 回の範囲・問題数を指定します（空欄・未指定なら全範囲）。
3. 「計算問題を始める」で画面上で解く、または「印刷する」ボタンでA4プリントを作成します。

## 📁 ファイル構成

- `index.html` - アプリ本体
- `data.js` - 理科の計算問題データ（`QA_DATA`、kosukequiz-battleの`data.js`内`kind:"calc"`の項目を移植）
- `images/` - 問題で参照する図版画像

## 🔄 データの更新方法

新しい回の理科データが`quiz_csv_理科`から届いたら、kosukequiz-battle担当セッションが計算問題（`kind:"calc"`）の項目だけをこの`data.js`に追記します（暗記系の項目はkosukequiz-battle本体側に追記）。
