## 背景

計算問題を印刷して紙で解いたところ、**図だけでは問題が解けないケース**がありました。
アプリ側で直せる部分（出題順・親子の並び）は対応済みですが、
**画像の切り出し範囲そのものは作成担当の領分**なので、こちらをお願いします。

現在の `images/` の図版は「図だけ」の切り出しになっていて、
リード文・条件・設問文が入っていません。条件は問題文（`q`）にテキストで
書き直されていますが、それでも解けないものが残っています。

具体例（第2回・発展問題）：

- `r2c69` 発展問題(1)「おもりA(260g)、台ばかり、半径の比が1:2:3の輪軸…」← 条件は全部ここ
- `r2c70` 発展問題(2)「**同じ装置で**、容器Eの中に水を…」← これ単体では解けない

トリミングが図の内側に食い込んでいる例もあります：

- `r2_21.jpg` … 図の左端にある「40g」の数字が途中で切れていて、「0g」に見える

## お願いしたいこと（3点）

1. **テキストの前から順に、素直に切り出してください**
   ページの掲載順そのままで構いません。並べ替えや取捨選択は不要です。

2. **「（2）」だけを切り出さないでください**
   親問（リード文・条件・図）がないと答えられません。
   **答えるのに必要な範囲をひとまとまり**として切ってください。
   具体的には、大問のリード文＋図＋その大問に属する小問（1)(2)(3)… までを1枚に含める形です。

3. **出題順はテキストどおりで**
   ランダムにはしません（アプリ側は対応済みです）。

## 守っていただきたいこと

- **問題id（`r2c01` などの `id`）は変えないでください。**
  アプリ側で「正解した問題」の記録を id をキーにして持つようにしました。
  id を振り直すと、記録が別の問題に紐づいてしまいます。
- **画像ファイル名は今のまま**にしていただけると、`data.js` の `img` を触らずに済みます。
  1枚に複数の小問をまとめた結果、枚数が減る場合は、
  どの画像がどの画像に統合されたかを教えてください。こちらで `data.js` の `img` を直します。
- 配置先はこれまでどおり `quiz_csv_理科\画像プレビュー\` と `kosukequiz-battle\images\` の両方でお願いします。
  そこから `keisan-print-app\images\` に反映します。
